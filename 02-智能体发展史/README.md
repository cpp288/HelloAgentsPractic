# 第二章　智能体发展史

> 本章无配套练习代码，重点理解「问题驱动」的范式迭代：每一代新范式都是为解决上一代的根本局限而生。

## 主线脉络
智能体发展不是直线迭代，而是**符号主义 → 联结主义/行为主义 → 大模型融合**的半个多世纪的思想交织。核心是三场关于「如何定义智能、如何获取知识、如何决策」的范式革命。

## 1. 符号主义（Symbolicism）：知识 + 推理
- **理论基石**：物理符号系统假说（PSSH，Newell & Simon, 1976）——「智能的本质就是符号的计算与处理」，含充分性 + 必要性两个论断。
- **代表成果**：
  - **专家系统**：知识库（IF-THEN 产生式规则）+ 推理机，知识与推理分离。推理方式分**正向链**（数据驱动）和**反向链**（目标驱动）。案例 MYCIN：约 600 条规则、反向链推理、引入置信因子（CF）处理不确定性。
  - **SHRDLU**（Winograd）：积木世界，首次把语言理解、规划、记忆、行动集成为「感知-思考-行动」闭环，奠定现代智能体雏形。
- **根本局限**（80 年代暴露）：
  1. **知识获取瓶颈 + 常识问题**：靠人工编码规则不可扩展，内隐/常识知识难以符号化（Cyc 项目数十年仍有限）
  2. **框架问题**：动态世界中难以高效判断「哪些没变」
  3. **系统脆弱性**：规则外的微小变化即失灵

## 2. 规则系统的实践印证：ELIZA（Weizenbaum, 1966）
- 机制：**模式匹配 + 文本替换**，四步——关键词识别排序 → 带通配符 `*` 的分解规则 → 重组规则 → 代词转换（I↔you）。
- 本质：完全不理解语义，靠句式转换营造「共情」假象（即 **ELIZA 效应**，用户竟对它产生情感依赖）。
- 三大局限：**缺乏语义理解**（如处理不了否定词）、**无上下文记忆**（无状态）、**规则扩展性差**（组合爆炸）。直接印证符号主义「穷举规则不可扩展」的核心矛盾。

## 3. 马文·明斯基「心智社会」（Society of Mind）：分布式智能的萌芽
- 反思：反对「单一全能中央处理器 + 统一逻辑」的自上而下模型。
- 核心观点：智能源于**大量简单、甚至「无心」的专门化智能体之间的协作涌现**，而非某个完美原理。简单智能体组成机构（Agency），靠去中心化的激活/抑制信号交互，复杂行为自发涌现（如搭积木塔）。
- 历史影响：为**分布式人工智能（DAI）和多智能体系统（MAS）**奠基——去中心化控制、涌现式计算（蚁群/粒子群优化）、智能体社会性（通信协议、协商、信任）。

## 4. 学习范式的演进
| 范式 | 解决的问题 | 关键点 |
|---|---|---|
| **联结主义** | 感知（图里有什么） | 知识以**连接权重**分布式存储；自下而上；反向传播调整权重；赋予模式识别能力 |
| **强化学习（RL，行为主义）** | 决策（该做什么） | 五要素：Agent / Environment / State / Action / Reward；策略 π；「感知-行动-学习」闭环；目标是**最大化累积奖励（回报）**，需远见（如围棋弃子）；案例 AlphaGo |
| **预训练 + 微调** | 先验世界知识 | 在海量文本上自监督学习（预测下一个词）→ 少量标注微调；**解决了符号主义的知识获取瓶颈**；规模跨越阈值后出现**涌现能力**（上下文学习、思维链） |

## 5. LLM 驱动的现代智能体（技术融合）
三大思潮在 2020 年代深度融合：LLM（联结主义产物）成为执行符号推理、工具调用、规划决策的「大脑」，形成**神经-符号结合**的现代架构。

核心循环（第一章已学，本章从架构组件细化）：
**感知 Perception → 思考 Thought（规划模块分解目标 + LLM 推理 + 记忆）→ 行动 Action（执行模块 + 工具调用）→ 观察 Observation（工具结果 + 新环境状态）→ 回到感知**

## 6. 本章关键收获
- 理解现代智能体「从何而来」：符号主义给了推理框架，联结主义给了感知，RL 给了决策能力，LLM 给了世界知识与通用推理。
- 智能体演进是思想变革，不只是技术迭代：每代范式都解决了前代痛点，又引入新局限，驱动下一代诞生。

## 附录：大白话理解版

> 上面是精简的正式总结，这一节用大白话重讲一遍，帮你建立直觉。

**一句话总览**：人类搞了 70 年「让机器变聪明」，每一代方法都解决了上一代的毛病，但又冒出新毛病，最后在大模型这里把各路功夫融合到了一起。理解这条「问题驱动」的演进线，比记住每个名词都重要。

### ① 符号主义：把道理一条条写死给机器
最早大家想：人会思考是因为脑子里有规则，那我把规则一条条写进电脑，电脑不就聪明了吗？这就是符号主义。

代表成果：
- **专家系统**：把医生经验写成一堆「如果……那么……」，机器照着推。当年 MYCIN 看病能达到普通医生水平。
- **SHRDLU**：在「积木世界」里能听懂人话、自己规划搬积木，是第一个把「听懂→想清楚→动手」串成闭环的系统，现代智能体的老祖宗。

但问题是致命的：
1. **写不完**——真实世界的常识无穷无尽，不可能全写成规则（知识获取瓶颈）；
2. **太脆弱**——规则是死的，遇到没写过的情况就彻底傻掉。

> 打比方：像一本超厚菜谱，每道菜步骤都写死。菜谱写得再全，遇到菜谱里没有的食材，厨师就不知道怎么办了。

### ② ELIZA：亲手感受规则法为什么不行
教材让你复现 1966 年的聊天机器人 ELIZA，就是让你亲手踩一遍符号主义的坑。

ELIZA 装作心理医生，你说「我很难过」它回「你为什么难过呀」。看起来懂你，其实**完全不理解你在说什么**，只是机械地：匹配关键词 → 把你的话改成问句抛回来 → 匹配不上就回「请继续说」。

一跑就会发现三个毛病：
- 不懂意思（认不出「不」这个否定词）；
- **记不住**上一句聊了啥（无状态）；
- 想让它更聪明只能不断加规则，加着加着规则互相打架、维护不动（组合爆炸）。

诡异的是很多人聊出了感情，觉得它懂自己——这就是「**ELIZA 效应**」：人会自己脑补机器的智能。

> 这一段的目的就是让你**用代码亲手证明**：靠写规则这条路走不远。

### ③ 明斯基「心智社会」：别造全能大脑，造一群小笨蛋协作
符号主义搞不下去，大佬明斯基说：你们思路错了！总想造一个全知全能的中央大脑，但人类智能根本不是这样——「理解」其实是几十种小能力（视觉、逻辑、情感、常识……）凑在一起的结果。

他提出：智能不是来自一个完美大脑，而是来自**一大堆简单到「没脑子」的小单元，各自干一件小事、互相协作，最后「涌现」出看起来很聪明的行为**。比如搭积木塔，没有总指挥，「找积木/伸手/抓住/放上去」这些小模块自己被激活、互相配合，塔就搭起来了。

> 打比方：像蚁群。没有一只蚂蚁知道「我们要建蚁穴」，每只只做最简单的事，一群凑一起，复杂蚁穴就「涌现」出来了。

这个想法直接启发了后来的**多智能体系统**（多个独立程序协作）——现在的 MetaGPT、CrewAI 根子都在这。

### ④ 学习范式的三次进化：别再教它了，让它自己学
符号主义的死结是知识靠人写、写不完。那能不能让机器自己学？三个关键能力依次被攻克：

- **联结主义** → 解决「看懂世界」：模仿大脑神经网络，知识存在神经元连接权重里，给海量数据它自己学。机器终于能看懂图、听懂话了。
- **强化学习** → 解决「做决策」：让机器在环境里瞎试，做对了给奖励、做错了扣分，试几百万次自己摸索出最优策略。典型例子 AlphaGo，不靠人喂棋谱，自己跟自己下了几千万局。
- **预训练** → 解决「先有常识再干活」：先让它把全人类文字读一遍、自带世界知识，再去干具体活。这正好补上了符号主义当年「常识写不完」的窟窿；模型大到一定程度还会冒出没教过的新能力（涌现）。

### ⑤ 现代智能体：把所有功夫融合
到 2020 年代几条线汇合了：**大模型本身是学出来的（联结主义），但它现在能当「大脑」去做符号推理、去规划、去调用工具**。于是形成现代智能体的循环：收到指令 → 想一想（分解任务+推理+记历史）→ 动手（调工具）→ 看结果 → 再想 → 再动……直到完成。这就是第一章你亲手写的那个「查天气→推荐景点」Agent 背后的原理。

### 一句话串起来
> 最早想「把规则写死让机器聪明」→ 发现写不完、太脆 → 有人说「不如让一群小模块自己协作」→ 又发现「得让机器自己学」→ 先学会看（联结主义）、再学会决策（强化学习）、最后先读遍天下书打底子（大模型预训练）→ 合起来，就是今天你在用的智能体。
