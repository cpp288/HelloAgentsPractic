# 第二章　智能体发展史

> 本章无配套练习代码，重点理解「问题驱动」的范式迭代：每一代新范式都是为解决上一代的根本局限而生。

## 主线脉络
智能体发展不是直线迭代，而是**符号主义 → 联结主义/行为主义 → 大模型融合**的半个多世纪的思想交织。核心是三场关于「如何定义智能、如何获取知识、如何决策」的范式革命。

## 1. 符号主义（Symbolicism）：知识 + 推理
- **理论基石**：物理符号系统假说（PSSH，Newell & Simon, 1976）——「智能的本质就是符号的计算与处理」，含充分性 + 必要性两个论断。
- **代表成果**：
  - **专家系统**：知识库（IF-THEN 产生式规则）+ 推理机，知识与推理分离。推理方式分**正向链**（数据驱动）和**反向链**（目标驱动）。案例 MYCIN：约 600 条规则、反向链推理、引入置信因子（CF）处理不确定性。
  - **SHRDLU**（Winograd）：积木世界，首次把语言理解、规划、记忆、行动集成为「感知-思考-行动」闭环，奠定现代智能体雏形。
- **根本局限**（80 年代暴露）：
  1. **知识获取瓶颈 + 常识问题**：靠人工编码规则不可扩展，内隐/常识知识难以符号化（Cyc 项目数十年仍有限）
  2. **框架问题**：动态世界中难以高效判断「哪些没变」
  3. **系统脆弱性**：规则外的微小变化即失灵

## 2. 规则系统的实践印证：ELIZA（Weizenbaum, 1966）
- 机制：**模式匹配 + 文本替换**，四步——关键词识别排序 → 带通配符 `*` 的分解规则 → 重组规则 → 代词转换（I↔you）。
- 本质：完全不理解语义，靠句式转换营造「共情」假象（即 **ELIZA 效应**，用户竟对它产生情感依赖）。
- 三大局限：**缺乏语义理解**（如处理不了否定词）、**无上下文记忆**（无状态）、**规则扩展性差**（组合爆炸）。直接印证符号主义「穷举规则不可扩展」的核心矛盾。

## 3. 马文·明斯基「心智社会」（Society of Mind）：分布式智能的萌芽
- 反思：反对「单一全能中央处理器 + 统一逻辑」的自上而下模型。
- 核心观点：智能源于**大量简单、甚至「无心」的专门化智能体之间的协作涌现**，而非某个完美原理。简单智能体组成机构（Agency），靠去中心化的激活/抑制信号交互，复杂行为自发涌现（如搭积木塔）。
- 历史影响：为**分布式人工智能（DAI）和多智能体系统（MAS）**奠基——去中心化控制、涌现式计算（蚁群/粒子群优化）、智能体社会性（通信协议、协商、信任）。

## 4. 学习范式的演进
| 范式 | 解决的问题 | 关键点 |
|---|---|---|
| **联结主义** | 感知（图里有什么） | 知识以**连接权重**分布式存储；自下而上；反向传播调整权重；赋予模式识别能力 |
| **强化学习（RL，行为主义）** | 决策（该做什么） | 五要素：Agent / Environment / State / Action / Reward；策略 π；「感知-行动-学习」闭环；目标是**最大化累积奖励（回报）**，需远见（如围棋弃子）；案例 AlphaGo |
| **预训练 + 微调** | 先验世界知识 | 在海量文本上自监督学习（预测下一个词）→ 少量标注微调；**解决了符号主义的知识获取瓶颈**；规模跨越阈值后出现**涌现能力**（上下文学习、思维链） |

## 5. LLM 驱动的现代智能体（技术融合）
三大思潮在 2020 年代深度融合：LLM（联结主义产物）成为执行符号推理、工具调用、规划决策的「大脑」，形成**神经-符号结合**的现代架构。

核心循环（第一章已学，本章从架构组件细化）：
**感知 Perception → 思考 Thought（规划模块分解目标 + LLM 推理 + 记忆）→ 行动 Action（执行模块 + 工具调用）→ 观察 Observation（工具结果 + 新环境状态）→ 回到感知**

## 6. 本章关键收获
- 理解现代智能体「从何而来」：符号主义给了推理框架，联结主义给了感知，RL 给了决策能力，LLM 给了世界知识与通用推理。
- 智能体演进是思想变革，不只是技术迭代：每代范式都解决了前代痛点，又引入新局限，驱动下一代诞生。
